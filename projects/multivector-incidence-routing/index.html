How the method works

Input graph → local residual GINE backbone → endpoint-conditioned sigmoid incidence scores → auxiliary cycle/bridge event head → hard partition and continuous transport branches → gated multivector feedback → invariant graph pooling and a classification head.

Hard membership uses top-priority incidence selections and connected components on the full face poset. Exact ties are retained. Membership is discrete and stop-gradient; continuous embeddings inside a fixed block can still receive gradients. Soft transport has no top-1 selection and can carry gradients through continuous weights. The browser computes forward teaching values; it does not train or differentiate a model.

Try C24 and C12 + C12 with uniform priorities and constant features: the local analogy gives identical states, but blocks have cardinalities (24,24) versus two blocks of (12,12). Cardinality features reveal a distinction; no classifier prediction is implied.

What is real vs illustrated?

Graph editing, exact-tie partitioning, cell counts and the optional bridge overlay are computed algorithms. Scores, event probabilities, local scalar states, transport and block feedback are educational quantities. No trained graph or edge-event predictions are available. The GIF is illustrative.

Experiments

The supplied specification reports separate cohorts: connectivity C24 vs C12 + C12, GINE 50.00% and MVF feedback 88.89% balanced accuracy; cycle-conditioned BZR, GINE 70.62% and learned hard + soft 75.76%; common topology-supervision cohort, BZR 72.55%, COX2 68.72%, DHFR 76.18%. These are reported study results, not outputs of this demo. Shuffled and uniform controls are relevant comparisons; results across cohorts do not establish superiority.

Limitations

Scalar analogies omit learned vector maps and training. Graphs are limited to 30 vertices and 60 simple undirected edges. Ground-truth bridge detection is solely an educational overlay. Event classification does not guarantee better graph classification. The learned maps and trained-model numerical agreement must be validated before inference is integrated.
